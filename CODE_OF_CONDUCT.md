# Codice di condotta

Partecipando a questo progetto ti impegni a mantenere un ambiente rispettoso e accogliente per tutti.

- Sii cortese e costruttivo; critica le idee, non le persone.
- Niente molestie, insulti, discriminazioni o attacchi personali.
- Accetta le critiche con spirito aperto e assumi la buona fede degli altri.

I maintainer possono rimuovere commenti, issue o contributi che violano queste regole e, nei casi gravi,
escludere chi li ha scritti. Per segnalare un problema apri una issue riservata o contatta il maintainer
attraverso il profilo GitHub del repo.

Ispirato al [Contributor Covenant](https://www.contributor-covenant.org/it/version/2/1/code_of_conduct/).
